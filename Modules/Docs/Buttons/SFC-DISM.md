# SFC + DISM - Riparazione Sistema

## Descrizione
Esegue la scansione e riparazione dei file di sistema danneggiati.

## Cosa fa
1. SFC scannow - Verifica l'integrita dei file di sistema protetti
2. DISM RestoreHealth - Ripara l'immagine di sistema

## Quando usarlo
- Quando Windows presenta errori o crash frequenti
- Dopo un aggiornamento problematico
- Per risolvere problemi di stabilita

## Avvertenze
- Richiede privilegi amministrativi
- Puo richiedere molto tempo (20-60 minuti)
- Riavvio consigliato dopo l'esecuzione
