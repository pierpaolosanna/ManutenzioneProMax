# Store - Aggiornamento App Microsoft Store

## Descrizione
Aggiorna tutte le applicazioni installate dal Microsoft Store.

## Cosa fa
- Cerca aggiornamenti per tutte le app dello Store
- Scarica e installa le nuove versioni
- Avvia lo Store in background per download e aggiornamenti

## Quando usarlo
- Per mantenere aggiornate le app UWP/Store
- Quando un'app dello Store non funziona correttamente

## Avvertenze
- Richiede connessione internet
- Alcune app potrebbero richiedere il riavvio
