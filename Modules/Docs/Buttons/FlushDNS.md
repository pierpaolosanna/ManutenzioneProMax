# Flush DNS - Svuota Cache DNS

## Descrizione
Svuota la cache DNS locale del computer.

## Cosa fa
- Rimuove tutti i record DNS memorizzati nella cache
- Forza il sistema a richiedere nuovi record DNS

## Quando usarlo
- Quando un sito non si apre correttamente
- Dopo aver cambiato server DNS
- Per risolvere problemi di risoluzione nomi

## Avvertenze
- Non richiede riavvio
- Effetto immediato
